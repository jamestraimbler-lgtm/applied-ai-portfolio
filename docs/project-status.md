## A useful endpoint

Each project leaves a problem, the part that exists, evidence appropriate to
the claim, a result and a remaining gap. Research can end with “the hypothesis
did not earn further investment.” A prototype can end with a documented
interface and a clearly named unfinished path.

The Python examples can be run here. The marketplace excerpts can be read
but are not standalone software. The video frame illustrates a retained
completed artifact; its full render is available for a walkthrough. These
different evidence types do not inherit the Python examples' passing tests.

## Reopening a track

Name one user, one problem, one deliverable and one acceptance check. Product
work needs a reason to believe the user wants it. Research needs a new
falsifiable question and a fixed evaluation budget. This register makes the
current work understandable; it does not promise to finish every old project.
